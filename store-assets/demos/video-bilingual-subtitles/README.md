## 逐句解说

1. 看外语视频时，听懂每一句并不容易。
2. 打开只译的视频字幕翻译，原文和译文会同步显示。
3. 字幕跟随播放进度更新，不用暂停，也不用反复切换页面。
4. 保留原文方便核对，也让理解变得更轻松。

逐句 TTS、源录屏和无旁白中间成片作为本地制作素材保留，不提交仓库。
