# EPUB 双语阅读 Demo

主题：导入本地电子书，沿着章节继续双语读

## 公开示例

- 书名：Lewis Carroll《Alice’s Adventures in Wonderland》
- 来源：Project Gutenberg eBook #11
- 页面：https://www.gutenberg.org/ebooks/11
- 许可：Public domain in the USA
- 用途：演示只译导入本地无 DRM EPUB、章节翻译、双语显示与本地阅读状态

## 逐句配音

1. 只译内置了一个本地 EPUB 阅读器。
2. 导入电子书，就能按章节生成双语内容。
3. 原文和译文同时保留，阅读时可以随时对照。
4. 翻到下一章，译文很快跟上。看到哪里，就翻译到哪里。
