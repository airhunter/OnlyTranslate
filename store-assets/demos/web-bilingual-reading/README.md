# 网页双语阅读 Demo

主题：英文文章，不离开原网页直接双语读

## 成片

- `onlytranslate-web-bilingual-horizontal.mp4`
  - 1920 × 1080
  - 30 fps
  - 32 秒
  - 用于 X、B 站横屏发布
- `onlytranslate-web-bilingual-vertical.mp4`
  - 1080 × 1920
  - 30 fps
  - 32 秒
  - 用于即刻和竖屏信息流

`poster-horizontal.png` 和 `poster-vertical.png` 是正文与译文同屏时的封面候选帧。

## 内容

1. 英文文章留在原网页阅读。
2. 选择「双语对照 + 识文」并开始翻译。
3. 译文跟在原文后面出现。
4. 正文进入双语阅读，导航和侧栏尽量保持原样。
5. 结尾引导用户在 Chrome Web Store 搜索「只译」。

素材使用仓库中已有的真实网页识文截图。视频不包含 API Key、邮箱、头像、书签栏或其他个人信息。
