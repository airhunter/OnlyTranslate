## 长描述

```text
只译 - 给认真读外语内容的人：网页、视频字幕、EPUB 和 PDF 都能双语翻译。

网页文章、视频字幕、本地 EPUB 和 PDF，都可以在同一套浏览器扩展里双语阅读。只译免费开源，不需要注册只译账号，也不绑定订阅；翻译服务由你自己选择。

为什么是“只译”？

很多翻译工具会把整页都变成另一种语言，但真正阅读时，你更需要的是：正文保持原来的结构，译文贴在阅读位置，导航、订阅、推荐列表和页面噪声尽量不打扰。

只译的「识文」模式会优先寻找网页中的主要阅读区域，适合文章、博客、新闻、技术资料和长帖。需要覆盖更多文本时，也可以切换到「全页」模式。

核心功能：

1. 网页双语阅读
- 识文 / 全页两种翻译范围
- 双语对照 / 仅译文两种阅读模式
- 保留原网页结构，译文跟随原文出现
- 支持右键菜单、快捷键和页面悬浮入口

2. 视频字幕翻译
- 支持 YouTube、Udemy、Coursera、Khan Academy 等有可读取字幕轨道的视频
- 结合上下文分段翻译字幕
- 播放过程中显示双语字幕，并用本地缓存减少重复请求

3. 本地 EPUB 和 PDF 翻译阅读（Beta）
- 导入本地无 DRM 的 EPUB 和 PDF，也可将能够直接访问的在线 PDF 保存到书架
- EPUB 支持章节翻译、目录导航、阅读进度和位置书签
- PDF 支持分页双语阅读、仅译文和保留版面翻译，并可导出原始文件
- 复杂 PDF 可由用户主动下载约 23 MB 的可选版面模型；模型只保存在浏览器本地，可随时移除
- 未下载模型、模型不可用或分析失败时会自动使用基础版面分析，不影响正常阅读
- 原始 EPUB/PDF 文件不会发送给翻译服务；只有开始翻译后，提取出的文本才会发送给你选择的服务商

4. 划词、悬停和输入框翻译
- 选中文字后查看译文
- 悬停预览文本翻译
- 在网页输入框旁生成译文候选，确认后再替换原输入

5. 自选翻译服务
- 免配置服务：微软翻译、Google 翻译、Chrome 内置翻译等
- AI 服务：OpenAI、DeepSeek、Gemini、Claude、DeepL 等主流服务
- 支持 OpenAI Chat Completions 兼容网关

6. 更轻、更专注的页面体验
- 网页翻译、划词、视频字幕和输入框翻译等功能按需启动
- 普通浏览时只加载轻量脚本，减少不使用翻译功能时的页面资源占用
- 内置简体中文、英文、繁体中文和日文帮助，可在设置中搜索使用说明

隐私与费用说明：

- 只译项目方不收集使用数据，不出售浏览记录，也不提供只译账号或订阅。
- 设置、缓存、EPUB/PDF 书架、阅读进度、书签和可选 PDF 版面模型保存在当前浏览器本地。
- 原始 EPUB/PDF 文件不会上传；只有开始翻译后，提取出的文本才会发送给你选择的翻译服务。PDF 版面模型在浏览器本地运行。
- 使用在线翻译服务时，待翻译文本会发送给你选择的服务商，并受该服务商的隐私政策约束。
- 部分服务需要 API Key，并可能由服务商按其规则收费。只译不会代替服务商管理账户、额度或账单。
- 字幕翻译依赖视频本身提供可读取的原字幕轨道；浏览器内部页、扩展商店和安全受限页面可能无法翻译。

适合这些场景：

- 阅读英文新闻、博客、技术文章和产品文档
- 看 YouTube / Udemy / Coursera 外语课程
- 读本地英文 EPUB、论文、报告和其他 PDF 文档
- 写外语输入框前先快速生成候选译文
- 希望使用免费开源、服务可自选的浏览器翻译扩展
```

## 隐私权规范

### `scripting` 权限理由

在 Chrome Web Store 后台的“隐私权规范”标签页中填写：

```text
只译使用 scripting 权限，按需向用户当前浏览的普通网页及对应 frame 注入扩展包内置的功能脚本和样式，以实现网页双语翻译、悬浮翻译、划词翻译、输入框翻译、视频字幕翻译和首次使用引导。注入仅在相关功能启用或由用户触发时发生，用于读取页面中的可见文本、插入译文及显示必要的交互界面。只译不会通过此权限下载、生成或执行远程代码，也不会将其用于广告、跟踪或修改与功能无关的页面。
```
