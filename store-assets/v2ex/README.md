# V2EX 宣传图片

`zh-CN` 中的五张图片均为 1280 × 800 PNG，由 Chrome Web Store 宣传素材源文件导出。

V2EX 首发正文建议只使用前三张：

1. `01-web-translation.png`：网页正文双语翻译
2. `02-video-subtitles.png`：视频双语字幕
3. `03-epub-reader.png`：EPUB 翻译阅读器（Beta）

备用图片：

4. `04-popup-library.png`：Popup 电子书书架
5. `05-services-privacy.png`：翻译服务选择和本地数据说明

源文件位于 `../chrome-web-store/source/listing.zh-CN.html` 和 `../chrome-web-store/source/listing.css`。修改源文件后，应重新导出图片，避免直接编辑生成的 PNG。
