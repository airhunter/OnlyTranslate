# プライバシー説明

最終更新日：2026 年 8 月 3 日

OnlyTranslate は無料・オープンソースのブラウザー翻訳拡張機能です。この説明では、ブラウザー内に保存される情報、テキストが第三者の翻訳サービスへ送信される条件、データを管理する方法について説明します。

## OnlyTranslate のアカウントは不要

OnlyTranslate にはプロジェクト側が運営するアカウントシステムがなく、ログインや購読も必要ありません。プロジェクトは、拡張機能を通じて通常の利用統計、閲覧履歴、翻訳履歴、読み込んだ電子書籍を収集しません。

## 任意のアンインストール時フィードバック

ブラウザーが対応している場合、OnlyTranslate をアンインストールすると、プロジェクトのウェブサイトにあるフィードバックページが開くことがあります。回答せずにページを閉じることも、主なアンインストール理由と初回利用時の問題を固定選択肢から任意で送信することもできます。

送信した場合、プロジェクトが保存するのは選択した分類、拡張機能のバージョン、表示言語、送信時刻だけです。専用フィードバックログには、IP アドレス、リクエストヘッダー、ページ URL、翻訳内容、ユーザー識別子を保存せず、フォームに自由記述欄もありません。ログはプロジェクトの問題を集計する目的でメンテナーだけが使用し、保存期間は最長 90 日です。

## ブラウザー内に保存されるデータ

次のデータは、現在のブラウザープロファイルに保存されます。

- 翻訳サービスとインターフェースの設定
- 翻訳結果と動画字幕のキャッシュ
- 読み込んだ EPUB ファイル
- 電子書籍の本棚、読書位置、位置ブックマーク
- 利用者が設定した第三者サービスのパラメーター

拡張機能のアンインストール、拡張機能データの消去、書籍の削除を行うと、対応するローカルデータが削除される場合があります。OnlyTranslate は現在、クラウド同期やリモートバックアップを提供していません。

## オンライン翻訳サービス

Microsoft Translator、Google 翻訳、DeepL、OpenAI、DeepSeek、Gemini、Claude、その他のオンラインエンドポイントを選択して翻訳すると、対象となるウェブページのテキスト、字幕、電子書籍の章テキストがそのサービスへ送信されます。

これらのリクエストには、選択したサービス提供者のプライバシーポリシー、アカウント規則、データ処理条件が適用されます。OnlyTranslate は、第三者サービスのアカウント、利用枠、請求、データ保持方針を管理しません。

現在のブラウザーと翻訳言語の組み合わせが Chrome 内蔵翻訳に対応している場合、テキストをブラウザー内で処理できます。利用可否は Chrome のバージョン、ローカルモデルの状態、言語の組み合わせによって異なります。

## API キーとサービス設定

入力した API キーとサービス設定は、ブラウザーの拡張機能ストレージに保存され、選択したサービスへのリクエストに使用されます。OnlyTranslate プロジェクトがこれらの認証情報を受信または保管することはありません。

公共の端末には個人用 API キーを保存しないでください。サービス提供者が対応している場合は、セキュリティ機能を使ってキーの権限や利用額を制限してください。

## EPUB データ

読み込んだ EPUB ファイル、本棚、読書位置、ブックマークは現在のブラウザーに保存され、OnlyTranslate プロジェクトへアップロードされません。翻訳を開始すると、現在の章で翻訳が必要なテキストが、選択した翻訳サービスへ送信されます。

電子書籍リーダーの初期バージョンは、ローカルの DRM なし EPUB のみに対応しています。

## キャッシュ

繰り返しのリクエストと待ち時間を減らすため、翻訳結果と動画字幕がローカルにキャッシュされる場合があります。OnlyTranslate ポップアップ右上の「その他」メニューからキャッシュを消去できます。
