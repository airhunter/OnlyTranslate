# 隐私说明

最后更新：2026 年 8 月 3 日

只译是一款免费、开源的浏览器翻译扩展。本说明用于解释只译会在浏览器中保存哪些信息、什么情况下会把文本发送给第三方翻译服务，以及用户可以如何管理这些数据。

## 不需要只译账号

只译不提供项目方账号系统，也不要求用户登录或订阅。项目方不通过扩展收集日常使用统计、浏览历史、翻译记录或导入的电子书。

## 可选的卸载反馈

在浏览器支持的情况下，卸载只译后可能会打开项目官网上的反馈页面。用户可以直接关闭页面，也可以自愿提交固定选项，说明主要卸载原因和首次使用障碍。

提交后，项目方只保存用户选择的分类、扩展版本、界面语言和提交时间。专用反馈日志不保存 IP 地址、请求头、网页地址、翻译内容或用户标识，也不提供自由文本输入。日志仅供项目维护者汇总产品问题，并最长保留 90 天。

## 保存在浏览器本地的数据

以下数据保存在当前浏览器配置中：

- 翻译服务与界面设置；
- 翻译结果和视频字幕缓存；
- 导入的 EPUB 文件；
- 电子书书架、阅读进度和位置书签；
- 用户主动配置的第三方服务参数。

卸载扩展、清除扩展数据或移除图书时，相应的本地数据可能被删除。只译目前不提供云同步或远程备份。

## 在线翻译服务

当用户选择微软翻译、Google 翻译、DeepL、OpenAI、DeepSeek、Gemini、Claude 或其他在线接口进行翻译时，需要翻译的网页文本、字幕或电子书章节文本会发送给相应服务商。

这些请求受所选服务商的隐私政策、账户规则和数据处理条款约束。只译不会替代第三方服务商管理账户、额度、账单或数据保留策略。

如果当前浏览器和语言组合支持 Chrome 内置翻译，文本可以在浏览器本地处理。其可用性取决于 Chrome 版本、本地模型状态和语言组合。

## API Key 与服务配置

用户填写的 API Key 和服务配置保存在浏览器扩展存储中，用于向所选服务发送请求。只译项目方不会接收或托管这些凭据。

请不要在公共设备上保存私人 API Key，并根据服务商提供的安全功能限制密钥权限和使用额度。

## EPUB 数据

导入的 EPUB 原文件、书架、进度和书签保存在当前浏览器中，不会上传给只译项目方。开始翻译后，当前章节中需要翻译的文本会发送给用户选择的翻译服务。

只译第一版电子书阅读器仅面向本地无 DRM 的 EPUB。

## 缓存

翻译结果和视频字幕可能缓存在本地，以减少重复请求和等待。用户可以从只译弹窗右上角的「更多」菜单中清除缓存。
