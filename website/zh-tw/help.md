# 使用說明

只譯目前主要支援 Chrome。擴充功能內也提供可離線查看與搜尋的完整說明；本頁整理安裝前最常用的資訊。

## 安裝

從 [Chrome 線上應用程式商店安裝只譯](https://chromewebstore.google.com/detail/%E5%8F%AA%E8%AF%91/hiajidipndfdngigicngbkhbjolggifi)，再把擴充功能固定到瀏覽器工具列。

也可以從 [GitHub Releases](https://github.com/airhunter/OnlyTranslate/releases) 下載發行套件並手動安裝。

## 第一次翻譯網頁

1. 開啟需要翻譯的一般網頁。
2. 點選瀏覽器工具列中的只譯圖示。
3. 選擇可用的翻譯服務。
4. 第一次使用建議選擇「雙語對照」與「識文」。
5. 點選「翻譯目前頁面」。

需要恢復頁面時，再次開啟擴充功能並點選「還原原文」。

## 識文還是全頁

### 識文

適合文章、部落格、貼文、留言與長篇內容。它會優先尋找正文與主要閱讀區域，減少選單、導覽、訂閱按鈕與側欄推薦帶來的干擾。

### 全頁

適合文件、後台、論壇、工具網站與資訊密集頁面。它會翻譯更多可見文字，也能在識文漏翻時作為備用模式。

## 影片字幕

只譯可以讀取支援網站既有的字幕軌，結合上下文分段翻譯，並依播放位置顯示雙語字幕。

目前主要支援：

- YouTube；
- Udemy；
- Coursera；
- Khan Academy。

影片必須已提供只譯能讀取的字幕。只譯目前不包含語音辨識，也無法為沒有字幕的影片產生字幕。

## 本機 EPUB

從擴充功能彈出視窗底部進入「電子書（Beta）」，點選「匯入 EPUB」，再選擇一本本機無 DRM 的 EPUB。

進入章節後，只譯會自動翻譯目前章節，並保存書庫、閱讀進度與位置書籤。第一版暫不支援 PDF、MOBI、雲端同步、筆記或 AI 內容分析。

## 翻譯服務

Microsoft Translator、Google 翻譯等免設定服務可直接使用。OpenAI、DeepSeek、Gemini、Claude、DeepL 等服務需要依各自規則填入 API Key。

部分服務可能收費或限制額度，實際規則由對應服務商決定。

## 常見問題

### 為什麼擴充功能商店與瀏覽器內部頁面不能翻譯？

Chrome 不允許一般擴充功能在擴充功能商店、瀏覽器設定與部分安全受限頁面執行。

### 為什麼識文漏掉一部分內容？

識文會優先判斷主要閱讀區域。可以捲動到動態內容出現後重新翻譯，或切換到全頁模式。

### 我的資料會上傳嗎？

設定、快取、書庫與閱讀進度都保存在瀏覽器本機。使用線上翻譯服務時，待翻譯文字會傳送給您選擇的服務商。詳情請見[隱私說明](/zh-tw/privacy)。

### 如何回報問題？

請前往 [GitHub Issues](https://github.com/airhunter/OnlyTranslate/issues)，並盡量提供：

- 發生問題的頁面網址；
- 目前使用的翻譯範圍與顯示模式；
- 選擇的翻譯服務；
- 問題重現步驟；
- 不包含私人資訊的截圖或錯誤訊息。
