# 隱私說明

最後更新：2026 年 8 月 3 日

只譯是一款免費、開源的瀏覽器翻譯擴充功能。本說明解釋只譯會在瀏覽器中保存哪些資訊、何時會把文字傳送給第三方翻譯服務，以及使用者可以如何管理這些資料。

## 不需要只譯帳號

只譯不提供專案方帳號系統，也不要求使用者登入或訂閱。專案方不會透過擴充功能收集日常使用統計、瀏覽紀錄、翻譯紀錄或匯入的電子書。

## 選擇性的解除安裝回饋

在瀏覽器支援的情況下，解除安裝只譯後可能會開啟專案官網上的回饋頁面。使用者可以直接關閉頁面，也可以自願提交固定選項，說明主要解除安裝原因與首次使用障礙。

提交後，專案方只保存使用者選擇的分類、擴充功能版本、介面語言與提交時間。專用回饋日誌不保存 IP 位址、請求標頭、網頁網址、翻譯內容或使用者識別碼，也不提供自由文字輸入。日誌僅供專案維護者彙整產品問題，最長保留 90 天。

## 保存在瀏覽器本機的資料

下列資料保存在目前的瀏覽器設定檔中：

- 翻譯服務與介面設定；
- 翻譯結果與影片字幕快取；
- 匯入的 EPUB 檔案；
- 電子書書庫、閱讀進度與位置書籤；
- 使用者主動設定的第三方服務參數。

解除安裝擴充功能、清除擴充功能資料或移除圖書時，對應的本機資料可能會被刪除。只譯目前不提供雲端同步或遠端備份。

## 線上翻譯服務

當使用者選擇 Microsoft Translator、Google 翻譯、DeepL、OpenAI、DeepSeek、Gemini、Claude 或其他線上介面進行翻譯時，需要翻譯的網頁文字、字幕或電子書章節文字會傳送給對應的服務商。

這些請求受所選服務商的隱私權政策、帳號規則與資料處理條款約束。只譯不會代替第三方服務商管理帳號、額度、帳單或資料保留政策。

如果目前的瀏覽器與語言組合支援 Chrome 內建翻譯，文字可以在瀏覽器本機處理。實際可用性取決於 Chrome 版本、本機模型狀態與語言組合。

## API Key 與服務設定

使用者填入的 API Key 與服務設定會保存在瀏覽器擴充功能儲存空間中，用於向所選服務傳送請求。只譯專案方不會接收或代管這些憑證。

請勿在公共裝置上保存私人 API Key，並在服務商提供相關安全功能時限制金鑰權限與使用額度。

## EPUB 資料

匯入的 EPUB 原始檔、書庫、進度與書籤會保存在目前瀏覽器中，不會上傳給只譯專案方。開始翻譯後，目前章節中需要翻譯的文字會傳送給使用者選擇的翻譯服務。

只譯第一版電子書閱讀器僅支援本機無 DRM 的 EPUB。

## 快取

翻譯結果與影片字幕可能保存在本機快取中，以減少重複請求與等待時間。使用者可以從只譯彈出視窗右上角的「更多」選單清除快取。
