# 使用帮助

只译主要支持 Chrome 浏览器。扩展内也提供可离线查看和搜索的完整帮助，这里保留安装前最常用的信息。

## 安装

从 [Chrome Web Store 安装只译](https://chromewebstore.google.com/detail/%E5%8F%AA%E8%AF%91/hiajidipndfdngigicngbkhbjolggifi)，然后把扩展固定到浏览器工具栏。

也可以从 [GitHub Releases](https://github.com/airhunter/OnlyTranslate/releases) 下载发布包并手动安装。

## 第一次翻译网页

1. 打开需要翻译的普通网页。
2. 点击浏览器工具栏中的只译图标。
3. 选择一个可用的翻译服务。
4. 初次使用建议选择「双语对照」与「识文」。
5. 点击「翻译当前页面」。

需要恢复页面时，再次打开扩展并点击「还原原文」。

## 识文还是全页

### 识文

适合文章、博客、帖子、评论和长内容。它会优先寻找正文和主要阅读区域，减少菜单、导航、订阅按钮和侧栏推荐带来的干扰。

### 全页

适合文档、后台、论坛、工具站和信息密集页面。它会翻译更多可见文字，也可以在识文出现漏翻时作为回退选项。

## 视频字幕

只译可以读取支持网站已有的原字幕轨道，结合上下文进行分段翻译，并根据播放位置显示双语字幕。

当前主要支持：

- YouTube；
- Udemy；
- Coursera；
- Khan Academy。

视频必须已经提供只译能够读取的字幕。只译目前不包含语音识别，也不能为没有字幕的视频生成字幕。

## 本地 EPUB

从扩展弹窗底部进入「电子书（Beta）」，点击「导入 EPUB」，选择一本本地无 DRM 的 EPUB。

进入章节后，只译会自动翻译当前章节，并保存书架、阅读进度和位置书签。第一版暂不支持 PDF、MOBI、云同步、笔记或 AI 内容分析。

## 翻译服务

微软翻译、Google 翻译等免配置服务可以直接使用。OpenAI、DeepSeek、Gemini、Claude、DeepL 等服务需要根据各自要求填写 API Key。

部分服务可能收费或限制额度，具体规则由相应服务商决定。

## 常见问题

### 为什么扩展商店和浏览器内部页面不能翻译？

Chrome 不允许普通扩展在扩展商店、浏览器设置和部分安全受限页面运行。

### 为什么识文漏掉了一部分内容？

识文会优先判断主要阅读区域。可以滚动到动态内容出现后重新翻译，或者切换到全页模式。

### 我的数据会上传吗？

设置、缓存、书架和进度保存在浏览器本地。使用在线翻译服务时，待翻译文本会发送给你选择的服务商。详情见[隐私说明](/privacy)。

### 如何报告问题？

请前往 [GitHub Issues](https://github.com/airhunter/OnlyTranslate/issues)，尽量提供：

- 问题页面的网址；
- 当前使用的翻译范围和显示模式；
- 选择的翻译服务；
- 复现步骤；
- 不包含私人信息的截图或错误提示。
