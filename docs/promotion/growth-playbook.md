## 反馈 Issue

现在不建议单独开“泛反馈征集”置顶 Issue。V2EX 没热度时，空 Issue 会显得更冷。

更好的时机：

- README 截图上线后。
- 至少发布 2-3 条短 demo 后。
- 有第一批真实反馈或明确路线图时。

更好的标题：

```text
场景征集：你希望只译优先优化哪类外语阅读？
```

Issue 目标不是收愿望清单，而是收场景：

```text
想收集一些真实使用场景，帮助决定后续优先级。

请尽量按这个格式反馈：

1. 你主要翻译什么：网页文章 / 技术文档 / 视频字幕 / EPUB / 输入框 / 其他
2. 目前使用什么工具
3. 最影响体验的问题是什么
4. 如果是网页漏翻或排版问题，请附 URL、浏览器版本、翻译模式和现象

只译会继续围绕“外语内容阅读”打磨，不一定会做大而全的翻译平台。
```

## 第一篇文章

优先写使用场景，不写发布稿。

推荐标题：

```text
我用一个浏览器扩展，把英文网页、YouTube 字幕和 EPUB 放进同一套双语阅读流程
```

备选标题：

```text
为什么我又做了一个浏览器翻译插件
用只译读英文 EPUB：一个更安静的双语阅读工作流
```

文章结构：

1. 我遇到的问题：外语内容分散在网页、视频、电子书里，工具也分散。
2. 我不想做什么：不做账号体系，不做订阅，不做社区，不把所有东西都变成 AI 平台。
3. 我想做什么：让翻译贴着阅读过程出现，尽量保留原文结构。
4. 三个真实场景：读技术文章、看 YouTube 课程、读本地 EPUB。
5. 为什么开源和自选服务：信任、隐私、成本、可替换。
6. 目前限制：Chrome 优先、EPUB Beta、字幕依赖原字幕、复杂网页仍可能漏翻。
7. 邀请反馈：不要泛泛提需求，最好给具体页面或使用场景。

结尾 CTA：

```text
如果你也经常读外语网页、看外语视频或读英文 EPUB，欢迎试试只译。比起“想要什么功能”，我更想知道你在哪个真实场景里卡住了。
```

## 短 Demo 脚本

统一规格：

- 20-40 秒。
- 录制 `1920x1080` 横屏，另裁一个 `1080x1920` 竖屏版本。
- 隐藏书签栏、邮箱、API Key、个人头像和历史记录。
- 每条只讲一个场景，不要堆功能。
- 画面里少放说明字，字幕用 4-5 句短句即可。

### Demo 1：网页双语阅读

标题：

```text
英文文章，不离开原网页直接双语读
```

镜头：

1. 打开一篇英文文章或技术博客。
2. 点击只译图标。
3. 选择“双语对照 + 识文”。
4. 页面正文出现译文，导航和无关区域尽量不被打扰。
5. 切换“还原原文”或“仅译文”。

字幕：

```text
读英文网页时，我不想跳到另一个翻译页。
只译会优先识别正文和评论。
原文结构保留，译文直接跟在阅读位置。
需要核对就双语，不需要就只看译文。
```

### Demo 2：YouTube 双语字幕

标题：

```text
YouTube 外语字幕，自动变成双语
```

镜头：

1. 打开一个有英文字幕的 YouTube 视频。
2. 展示原字幕。
3. 打开只译字幕翻译。
4. 播放几秒，出现双语字幕。
5. 快进一小段，展示字幕继续追上。

字幕：

```text
看外语视频时，逐句直译经常很别扭。
只译会结合上下文做分段翻译。
播放时自动预取，重复内容会走本地缓存。
适合课程、访谈和技术分享。
```

### Demo 3：EPUB 双语阅读

标题：

```text
本地 EPUB，也能滚动双语读
```

镜头：

1. 从 Popup 进入“电子书”。
2. 导入一本本地无 DRM EPUB。
3. 打开章节。
4. 滚动时当前章节出现译文。
5. 展示目录、书签或阅读进度恢复。

字幕：

```text
很多英文书不是网页，也不在在线平台里。
只译可以导入本地无 DRM 的 EPUB。
章节文字按需发送给你选择的翻译服务。
书架、进度和书签保存在浏览器本地。
```

## 发布渠道

第一层：产品和开源用户

- GitHub README、topics、Release notes。
- HelloGitHub：适合开源工具收录和长期曝光。
- Product Hunt：适合英文版首发，但要准备好 icon、gallery、tagline、首条评论和 2 张以上素材。
- Hacker News `Show HN`：适合等英文 README、无登录试用路径、demo 视频都准备好之后再发。

第二层：中文工具和效率用户

- 少数派 Matrix：写“真实使用流程”，不要写硬广。
- 掘金：写“开发者读英文技术资料的翻译工作流”。
- 知乎：回答“浏览器翻译插件推荐 / 如何高效读英文技术文档 / 如何翻译英文电子书”类问题。
- 即刻：发短 demo + 一句具体场景。
- B 站：三条 demo 合成一个 1 分钟视频。

第三层：垂直人群

- 英文阅读、语言学习、考研/留学英语相关社区：主推“通过双语对照读真实内容”。
- YouTube 学习、公开课、技术课程相关社区：主推字幕翻译。
- Kindle、EPUB、电子书阅读社区：主推本地 EPUB 和隐私边界。
- Chrome 插件、浏览器效率工具社区：主推免费开源、自选服务、无账号订阅。
